# ポケモンスリープ 厳選チェッカー

ポケモンスリープのきのみタイプ・食材タイプ・スキルタイプ（最終進化形）向けの厳選チェッカーです。選んだサブスキル・性格から1日あたりの期待値を計算し、無補正個体との比較や全パターン中の上位%・順位を表示します。使い方・ポケモンのデータ・タイプごとの計算は [`checker/README.md`](checker/README.md) にあります。

## 公開ページ

https://ryo-code-313.github.io/application/checker/

## 構成

- `checker/` — アプリ本体（画面・状態管理・タイプごとの計算エンジンとポケモンのデータ）
- `js/constants.js` — サブスキル・性格・げんきなどのゲームデータ（3タイプ共通）
- `js/calc.js` — 3タイプ共通の計算（げんきとおてつだいのタイミング、睡眠中のスキル抽選回数、天井カウンタ、サブスキルの抽選分布）。DOM非依存
- `js/format.js` — 表示用フォーマット関数
- `css/style.css` — 土台のスタイル（見た目は `checker/css/theme.css` で上書き）
- `index.html`・`ingredient/index.html`・`berry/index.html` — `checker/` へ移動するページ

## 共通の計算モデル

タイプごとの計算（何を数えるか、所持数の扱い、食材配列）は `checker/README.md` にあります。ここでは3タイプに共通の部分をまとめます。

### おてつだいのタイミング

- 表示おてつだい時間 = floor(基準おてつだい時間 × (1 − (Lv−1) × 0.002) × 性格 × (1 − サブスキル合計))。サブスキル合計の上限は35%、性格は↑0.9倍・↓1.075倍。Lv.50まで（3枠）は Lv.60、Lv.70まで（4枠）は Lv.70、Lv.80まで（5枠）は Lv.80 で計算する。サブスキルの枠は Lv.10 / 25 / 50 / 70 / 80 で開く（アップデートで4枠目が Lv.75 から、5枠目が Lv.100 から引き下げ）。Lv.70 を超えても同じ式が続くものとして計算する。
- いいキャンプチケット使用時は時間を1.2で割り、最大所持数は ceil(所持数 × 1.2)。
- げんきによる倍率（Ver.1.8.1以降）: 81以上 0.45 / 61〜80 0.52 / 41〜60 0.58 / 1〜40 0.66 / 0 は 1.0。
- げんきは起床時100（げんき回復ボーナス持ちは睡眠回復の上限が105）から、睡眠中も含めて10分ごとに1減る。回復スキルは考えない。
- 次のおてつだいにかかる時間は、ひとつ前のおてつだいが終わった時点のげんきで決まる。起床時の回復は進行中のおてつだいにも反映する。
- 睡眠は毎日8.5時間。タイミングの端数は日をまたいで持ち越すので、捨て日を回したあと8日分を平均する。

### スキル抽選（スキルタイプ）

- スキル確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + スキル確率アップ合計)。
- 連続不発の天井 = Floor[144000 / 基準おてつだい時間]（基準おてつだい時間で約40時間分。ミュウツーは62回）。
- 日中は常にタップする前提で、ストックは発生しない。
- 睡眠中はスキルとくいなので2回までストックでき、2回たまると抽選が止まる。
- 所持数が満タンになると「いつのまに育成」になり抽選されない。ただし満タンになったおてつだいのあと、キューに残る4回分は抽選される。
- 天井カウンタの分布を日ごとに追い、日をまたいで引き継ぐ。

### 上位%の分布

- サブスキルは1枠ごとに色を 金14% / 青33% / 白53% で抽選し、その色の中で未所持のものから均等に選ぶ（重複なし）。
- 性格は25種を等確率とし、↑↓をタイプの計算に効く補正（おてスピ・食材・スキル）とその他に分類する。
- すべての組み合わせの無補正比を数え上げて分布を作り、「その個体以上の無補正比になる確率」を上位%、「分布の中で自分より高い値の数 + 1」を順位とする。

### 考慮していないもの

- チーム全体のスキル発動回数による確率低下（スキルゲート）。しきい値は非公開で、チーム編成に依存するため。
- フレンドメダルによる1枠目の金確定、性格のげんき回復量補正。

## ローカルで動かす

ES modules を使っているため、`file://` で直接開くのではなく簡易サーバーが必要です。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/checker/` を開いてください。
