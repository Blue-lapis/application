# 厳選チェッカー（きのみタイプ・食材タイプ・スキルタイプ）

ポケモンスリープのきのみタイプ（最終進化形31匹）・食材タイプ（最終進化形40匹）・スキルタイプ（最終進化形54匹）向けの厳選チェッカーです。画面上部のタブでタイプを切り替えます。

- 食材タイプ: 狙い食材・食材配列・サブスキル・性格から、狙い食材の1日あたりの期待個数を計算します。
- きのみタイプ: サブスキル・性格から、1日あたりのきのみエナジーの期待値に、おてつだいボーナスでチームのほかの4匹が増やすエナジーを足した値を計算します。
- スキルタイプ: サブスキル・性格から、1日あたりのメインスキルの期待発動回数を計算します。

どれも無補正個体との比較と、全パターン中の上位%・順位を表示します。サブスキル・性格のデータ（`../js/constants.js`）、げんきとおてつだいのタイミング計算・睡眠中のスキル抽選・天井カウンタ・サブスキル抽選モデル（`../js/calc.js`）、土台のスタイル（`../css/style.css`）はリポジトリ直下の共通部分にあり、その計算モデルはリポジトリ直下の README.md にまとめています。

## 使い方

- 画面上部のタブでタイプを選び、その下の欄でポケモンを選びます。`?mon=flygon` のように URL でも指定でき、タブもそのポケモンのタイプになります。
- タブを切り替えると、そのタイプで前回選んだポケモンに戻ります。選んだポケモンと、食材タイプの狙い食材は次に開いたときにも使います。
- ポケモンやタイプを切り替えても、サブスキルと性格はそのまま残ります。食材配列は選び直しになります。
- 幅の広い画面では、入力を左、結果を右の2列に並べます。
- 性能の欄では、日中の受け取り（きのみタイプだけ。なし＝いつのまに育成 / 3時間ごと）といいキャンプチケット（なし / あり）をその場で切り替えられます。ほかの設定は「詳細」のダイアログで変え、今の値は「詳細」の横に要約して出します。選んだ値は次に開いたときも使います。
  - きのみタイプの詳細: ヒーラー（なし / 1匹 / 常に81%以上）、おてボのチーム効果（含めない / 含める）、げんきオールSの1回の回復量（整数）と1日の発動回数（小数第2位まで）。
  - 食材タイプ・スキルタイプの詳細: げんき（10分ごとに減少 / 常に81%以上）。
- サブスキルの上の切り替えで対象レベル（Lv.50まで＝3枠 / Lv.70まで＝4枠 / Lv.80まで＝5枠）を選びます。
- サブスキルは枠（Lv.10 / 25 / 50 / 70 / 80）をタップして、ダイアログで選びます。レベルの低い枠から順に入れ、手前の枠が空いている枠は選べません。1つ選ぶと次の空き枠に進み、すべての枠が埋まるとダイアログは自動で閉じます（直すときはもう一度開きます）。ダイアログの上の枠ボタンで入れ直す枠を切り替えられます。どこかの枠で選んでいるもの（枠のレベルが付いたもの）を押すとその枠から外れ、その枠の入力に移ります。途中の枠を外したときは、そこを埋めるまで後ろの枠は選べません。「全枠クリア」ですべての枠を空にします。
- ダイアログにはゲーム内の全17種を、金色サブスキルと系統×サイズ（M / S / L）の表で並べます。ほかの枠で選んでいるものにはその枠のレベルを付けます。そのタイプの計算に効かないもの（睡眠EXPボーナスなど）は「なし他」として計算します。
- 性格は、行が▲上昇・列が▼下降の5×5の表から名前で選びます。そのタイプの計算に効く補正がない性格（無補正と同じ結果になるもの）は薄い色で表示します。
- 上位%は「その個体以上の無補正比になる確率」、順位は「全パターン中の何位か」です。パターンは上位%の分布の行（無補正比の値ごとに1行）で、無補正比が同じ個体は同じ順位になります。
- 計算した上位%の分布はブラウザ（IndexedDB）に保存し、次からは計算せずに読み込みます。保存は最大300件で、最後に使ったのが古いものから消します。計算方法・ポケモンの基礎値・共通データが変わったときは、保存済みの分布を使わずに計算し直します。
- 記録はポケモンごとに、今の対象レベルと同じ枠の数のものだけを表示します。統合前の食材タイプ版・きのみタイプ版の記録もそのまま表示されます。
- 記録の行をタップすると、その個体の食材配列・サブスキル・性格を入力に戻し、結果と下の帯がその個体の値になります。今の入力と同じ記録には「表示中」を付けます。記録を順にタップして見比べられます。性格の名前がない古い記録は、上昇・下降の補正だけを戻します。
- 以前の URL（リポジトリ直下のミュウツー版・`../ingredient/`・`../berry/`）は、ポケモンの指定を引き継いでこのページに移動します。

## 構成

- `index.html` — マークアップ
- `css/theme.css` — 見た目「夜のノート」（生成りの地に夜空色の文字、タイプの色はアクセント。文字は Zen Kaku Gothic New、数字は Outfit。土台のレイアウトは `../css/style.css`）
- `js/types.js` — 食材タイプ・きのみタイプの定義をまとめる
- `js/state.js` — アプリ状態管理・localStorage永続化（記録は統合前と同じ `iglog`・`bflog` とスキルタイプの `sklog`、共通の設定は `ck` 接頭辞）
- `js/ui.js` — DOM描画・イベント処理
- `js/picker.js` — サブスキル・性格を選ぶダイアログの並びと表示名
- `js/worker.js` — 上位%の分布計算をバックグラウンドで実行するWeb Worker
- `js/distcache.js` — 計算した分布を IndexedDB に保存・読み込みする
- `js/main.js` — エントリーポイント
- `js/ingredient/` — 食材タイプの定義（`constants.js`）・期待値計算エンジン（`calc.js`、DOM非依存）・ポケモンの基礎値（`mons.js`）
- `js/berry/` — きのみタイプの定義・期待値計算エンジン・ポケモンの基礎値
- `js/skill/` — スキルタイプの定義・期待値計算エンジン・ポケモンの基礎値

### 計算モデル

「狙い食材の1日の期待個数」を、無補正個体（サブスキルなし・無補正性格）のうち狙い食材が最も多く取れる食材配列（フライゴンのアボカドなら AAA）の値で割った比を順位の基準にしています。

- おてつだい時間・げんき・いいキャンプチケット・日をまたぐ持ち越しは共通の計算モデル（リポジトリ直下の README.md）のとおり。
- 食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計)。
- 食材おてつだいでは、食材配列の3スロット（Lv.1 / Lv.30 / Lv.60）から均等に1つ選び、そのスロットの食材を拾う。
- 日中は常にタップする前提で、所持数はあふれない。
- 睡眠中は所持数0から始まり、きのみ（1個、きのみの数Sで2個）と食材（狙い以外も含む）で埋まっていく。所持数を超えた分は捨てられ、満タン後のおてつだいでは食材は増えない。
- 性格のスキル補正は食材に影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種を共通のモデルで、食材配列は各スロットの候補を等確率として数え上げる。

#### 考慮していないもの

- 食材ごとのエネルギー（狙い食材の個数のみで比較）。
- メインスキルの効果、おてつだいボーナスのチーム全体への効果（自分のおてつだい時間の短縮としてのみ計算）。

## きのみタイプ

### ポケモンのデータ

`js/berry/mons.js` の `MONS` にポケモンごとの基礎値（おてつだい時間・食材確率・最大所持数・1回あたりのきのみの個数・きのみの基礎エナジー・食材スロットの候補と個数）を持ちます。データは [RaenonX ポケスリ攻略ツール](https://pks.raenonx.cc/ja/pokedex) から 2026年9月25日に取得しました。

- 対象は、とくいが「きのみ」で、これ以上進化しないポケモンです。ピカチュウ(ハロウィン) のオレンジとパープルは基礎値が同じなので1つにまとめています。
- 食材確率は RaenonX の集計値です。集計件数が少ないポケモンは誤差が大きい可能性があります。いくつかのポケモンは [ポケモンスリープ個体値チェッカー](https://www.pokemonsleepdaifuku.com/) の参考値と照らし合わせ、差が0.3ポイント以内であることを確かめました。
- きのみのエナジーは、RaenonX の Lv.1〜100 の値が下の計算式と一致することを全ポケモンで確かめました。
- 最大所持数は、その姿で捕まえた個体の値です。進化で増える分は考慮していません。

### 計算モデル

「自分のきのみの1日の期待エナジー ＋ おてつだいボーナスによるチームへの効果」を、無補正個体（サブスキルなし・無補正性格）の自分のきのみエナジーで割った比を順位の基準にしています。

- おてつだい時間・いいキャンプチケット・日をまたぐ持ち越しは共通の計算モデル（リポジトリ直下の README.md）のとおり。げんきは次のとおり（きのみタイプだけ）。
- げんき: 起床時は睡眠による回復で100（げんき回復ボーナス持ちは105）。起床中・睡眠中を問わず10分ごとに1減り、0で止まる。ヒーラー（げんきオールS、チーム全員を回復）がいるときは、起床中（15.5時間）を1日の発動回数 + 1 等分した時刻に、1回ずつ回復量（既定18）だけ回復する（上限150）。睡眠中は回復せず、就寝時の値から減っていく。既定（18×3回）では就寝時61・起床直前11。1日の発動回数が小数（2.5回など）のときは、前後の整数回の日（2回と3回）が小数部分の割合で混ざるものとして、それぞれの値を平均する。「常に81%以上」はげんきによる倍率を常に0.45とする。
- 日中の受け取り: 「なし」は起床時に受け取り、次の起床まで所持数0から続けて追う（いつのまに育成）。「3時間ごと」は起床から3・6・9・12・15時間後にも受け取って所持数を0に戻し、区間ごとに所持数0から追う（最後の区間は睡眠をまたいで次の起床まで）。どの区間も下の規則で所持数を埋める。
- チームへの効果: 自分がおてつだいボーナスを持つとき、ほかのメンバー4匹（同じポケモン・サブスキルなし・無補正性格・同じパラメーター）のおてつだいスピードが5%上がったぶんのきのみエナジーの増加を足す。オフにすると自分のきのみエナジーだけで比べる。
- きのみ1個のエナジー = max(基礎 + Lv − 1, round(基礎 × 1.025^(Lv − 1)))。Lv.60（3枠）/ Lv.70（4枠）/ Lv.80（5枠）で計算する。
- きのみおてつだい1回で拾うきのみは、きのみタイプの2個（きのみの数Sで3個）。
- 満タンになるまでは、食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計) で食材おてつだいになり、それ以外はきのみおてつだい。食材おてつだいでは食材配列の3スロット（Lv.1 / Lv.30 / Lv.60）から均等に1つ選び、そのスロットの個数を拾う。
- 満タンになった後は、食材確率に関係なくすべてのおてつだいできのみ（きのみの数Sの効果込み）を拾い、所持数からあふれたきのみはエナジーになる（いつのまに育成）。満タンになったおてつだいであふれた食材は捨てられる。おてつだいキューに残った最大4回分はメインスキルの抽選にだけ使われ、拾うものはきのみになる。
- そのため、1日のきのみ = 1回あたりのきのみ × (おてつだい回数 − 満タンになる前の食材おてつだい回数)。食材確率は満タンになるまでの数回にしか効かず、所持数を増やすと満タンが遅れて食材おてつだいが増えるぶん、きのみのエナジーはわずかに減る。
- 食材配列は入力しない。各スロットの候補を等確率として、配列ごとの値を出現確率で平均する（たとえばトドゼルガは Lv.60 の候補がすべて4個なので、Lv.30 がオイル×2 かマメミート×3 かだけが効く）。
- 性格のスキル補正はきのみに影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種を共通のモデルで数え上げる。パラメーターごとに別の分布になる。

#### 考慮していないもの

- げんきオールS以外のヒーラースキル（げんきエールSなど）、睡眠中にストックされたヒーラーのスキルが起床時に発動すること、睡眠スコアによる起床時の回復量の違い。
- おてつだいボーナスの5%がほかのメンバーのおてつだいスピード上限35%に含まれるか（既定のほかのメンバーはサブスキルなしなので影響しない）。
- 食材とメインスキルによるエナジー（きのみのエナジーのみで比較）。満タンの間はスキルも抽選されない。
- 日曜夜から月曜朝にかけては満タン後にいつのまに育成へ移行しない（週の最終日だけの例外なので、毎日同じとして計算）。
- イベントボーナスの「通常のおてつだいで拾うきのみ+1」（いつのまに育成では効かない）。
- 性格のげんき回復量補正（どのタイプも、起床時のげんきは補正なしで計算）。

## スキルタイプ

### ポケモンのデータ

`js/skill/mons.js` の `MONS` にポケモンごとの基礎値（おてつだい時間・スキル確率・食材確率・最大所持数・食材スロットの候補と個数）を持ちます。データは [RaenonX ポケスリ攻略ツール](https://pks.raenonx.cc/ja/pokedex) から 2026年9月25日に取得しました。

- 対象は、とくいが「スキル」で、これ以上進化しないポケモン（伝説・イベント限定の姿を含む54匹）です。
- スキル確率・食材確率は RaenonX の集計値です。集計件数が少ないポケモンは誤差が大きい可能性があります。
- ミュウツーの基礎値は2300秒・スキル2.9%・食材16%・所持数24です。

### 計算モデル

「1日の期待スキル発動回数」を、無補正個体（サブスキルなし・無補正性格）の値で割った比を順位の基準にしています。計算は共通の計算モデル（リポジトリ直下の README.md）のとおりで、ポケモンごとに次の値を使います。

- スキル確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + スキル確率アップ合計)。
- 連続不発の天井 = Floor[144000 / 基準おてつだい時間]（基準おてつだい時間で約40時間分。ミュウツーは62回）。
- 日中は常にタップする前提でストックは発生しない。睡眠中は2回までストックでき、所持数が満タンになったあとはキューに残る4回分まで抽選される。
- 睡眠中の所持数は、きのみ（1個、きのみの数Sで2個）と食材（食材配列の3スロットから均等に1つ選んだ個数）で埋まる。食材配列は入力せず、配列ごとに天井カウンタを追った結果を出現確率で平均する。
- 性格はスキル・おてスピ・食材・その他に分類する。上位%の分布はサブスキル（色別抽選・重複なし）と性格25種をすべて数え上げる。
- 統合前のミュウツー版（食材を1/2/4個に固定）の記録は、スキルタイプのミュウツーの記録として一度だけ引き継ぐ。

#### 考慮していないもの

- メインスキルの効果量（発動回数のみで比較）と、チーム全体の発動回数による確率低下（スキルゲート）。
- フレンドメダルによる1枠目の金確定、性格のげんき回復量補正。

#### 出典

- 天井の式: [ポケモンスリープ攻略・検証 Wiki](https://wikiwiki.jp/poke_sleep/)（スキル発動回数期待値一覧）、[はりゅう: ポケモンスリープ 厳選(スキルとくい)](https://note.com/haryuuublog/n/n9820e93540f4)
