# ver1.5 要件定義：にとよんツールとの計算の一致

ver1.4（`2acda86`、PR #44）を土台に、食材タイプ・スキルタイプの期待値を [にとよんツール（ポケスリ 個体値計算機）](https://nitoyon.github.io/pokesleep-tool/iv/) に合わせる。作業ブランチは `claude/match-nitoyon-skill-ing`。

## 1. 現状

ver1.4 の値を、にとよんツールのソース（GitHub `nitoyon/pokesleep-tool`）で同じ条件の値と比べた。基礎値（おてつだい時間・食材確率・スキル確率・最大所持数・食材の個数）は全匹で同じだった。

| タイプ | 差（中央値 / 最大） | 主な原因 |
|---|---|---|
| 食材 | 0.02% / 2.1% | おてつだい時間の秒の切り捨て（3時間ごとの受け取りの境目で1回が前後の区間に移る） |
| スキル | 2.8% / 19% | 満タン後のキュー4回の抽選（大部分）、天井の式と天井カウンタの扱い（約0.4%） |

## 2. 方針

- おてつだい時間は、倍率の積を小数第4位まで切り捨てて基準の時間に掛け、秒は切り捨てない。
- 食材確率・スキル確率は小数第4位まで切り捨てる。
- 天井は Ceil[142000 / 基準おてつだい時間] 回の不発の次で発動とし、すべての抽選を天井込みの実質確率で数える。天井の途中経過は追わない。
- 満タン後にキューに残る4回の抽選は残す（ポケモンスリープ攻略・検証 Wiki「おてつだい」の「所持数最大に到達してから最大4回分のおてつだいではメインスキルが発動する可能性がある」による。にとよんツールとはここだけ違う）。
- おてつだいボーナスのチーム効果を含めた無補正比は ver1.4 の数え方のまま（ほかの4匹の増加分を足す）。
- ストリンダーの姿ごとの性格の制限は今回は扱わない。
- おてつだい時間はタイプ共通の計算なので、きのみタイプにも同じ変更が入る。

## 3. 完了条件

| 確認 | 条件 |
|---|---|
| にとよんツール | きのみ・食材は同じ条件の値の差が浮動小数の誤差の範囲（相対1e-12以下）。スキルはキュー4回を除けば同じ |
| 整合性 | `node tests/check-dist.mjs` が通る |
| 境目 | 所持数・ストック2回・小数回数・実質確率を、小さな全経路の列挙と比べる（`tests/check-segs.mjs`） |
| 保存 | `MODEL_VERSION` を8から10に上げる（9は #45 の、キュー4回を除いた版） |

実装後に `design-v1.5.md` と README に作り・検証結果を記す。
