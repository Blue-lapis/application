## 2. 食材タイプの計算エンジン（`checker/js/ingredient/calc.js`）

1. **倍率** `mk`: きのみタイプと同じ形にし、性格のげんき回復量補正 `rec` とおてつだいボーナス `hb` を加える。性格の分類に「げんき回復」を加える。
2. **スケジュール**: きのみタイプと同じく `curveOf` → `helpsPerTap` で、受け取りの区間ごとに小数のおてつだい回数を求める。
   - 常にタップ: 日中は1区間（所持数はあふれない）、睡眠中は所持数0から起床まで。
   - 3時間ごと: 起床から3・6・9・12・15時間後と就寝時に区切る。
3. **所持数**: 区間ごとに所持数0から追い、満タンになった後は食材が増えない（今の `nightIngredients` を、食材ごとの個数を返す形に広げる）。日中の「常にタップ」の区間は所持数を見ない。回数が小数なら前後の整数回の結果を線形に混ぜる。最大所持数に `evo × 5` を含める。
4. **値**: 食材ごとの期待個数 `ings = { 食材名: 個数 }`。
   - `energyOf(ings) = Σ 個数 × ING_ENERGY[食材]`
   - `value = energyOf(ings) + (env.team && m.hb ? 4 × teamGain(env) : 0)`
   - `baseMetric` = 無補正個体で `value` が最大の食材配列の値。
5. **発動回数が小数**: `timesMix` / `mixed` で前後の整数回の日を平均する（きのみタイプと同じ）。
6. **分布** `buildDist`: サブスキル × 性格25種 × 食材配列（`slotWeights`）。狙い食材には依存しないので、`envKey` から `target` を外す。

## 3. チーム効果のライチュウ（`checker/js/ingredient/team.js`）

きのみタイプのエンジン（`createEngine`・`prepare`）は Lv を枠数から決めるため Lv.50 を扱えず、受け取りに「常にタップ」もない。そこで、きのみタイプの部品関数だけを使って、食材タイプ用の小さな計算を別に作る。

- 条件: `MONS.raichu`（きのみタイプのデータ）、Lv.50、いじっぱり（↑おてスピ ↓食材）、きのみS・おてスピM、3枠目は空き。所持数は進化2回ぶんの +10 を含める。
- ヒーラー・回復量・発動回数・いいキャンプチケットは食材タイプの `env`（きのみタイプと共通の設定）をそのまま使う。
- 受け取り:
  - 3時間ごと: きのみタイプの「3時間ごと」と同じ（`segBerries` を区間ごとに使う）。
  - 常にタップ: 日中は `Ha × きのみの数 × (1 − 食材確率)`、睡眠中は `segBerries`（所持数0から起床まで）。
- 食材配列はきのみタイプと同じく出現率で平均する。
- `teamGain(env)` = おてつだいスピード +5% ありのきのみエナジー − なし。条件ごとに1回だけ計算してキャッシュする（個体によらないので分布の計算は重くならない）。
- 確かめ方: 受け取り「3時間ごと」の値が、きのみタイプの同じ条件の計算（Lv と個体を合わせたもの）と一致することをテストで確かめる。

## 4. 画面（食材タイプの結果）

- 大きく出す値: 狙い食材の個数（日中 / 睡眠中の内訳）。同じ枠に、そのエナジーを小さめに出す。
- その他の食材: 食材ごとの個数と、小さめにエナジー。
- チーム効果: おてボ持ちで「含める」のときだけ「ライチュウ4匹のきのみ +○○エナジー」。
- 合計: 順位の基準（エナジー）を小さめに出す。無補正比・同等以上の確率・何匹に1匹はこの値で出す。
- パラメーター: メインに「日中の受け取り（常にタップ / 3時間ごと）」「いいキャンプチケット」。詳細ダイアログにヒーラー・回復量・発動回数（きのみタイプと共通）・おてボのチーム効果。

## 5. 保存・移行

- 受け取りは食材タイプ用に別に保存する（`ckingtap`。きのみタイプの `cktap` とは選択肢が違うため）。
- ヒーラー・回復量・発動回数はきのみタイプと同じキー（`ckheal`・`ckhealamt`・`ckhealtimes`）を使う。以前の食材タイプの「常に81%以上」の保存値は、共通の設定がないときだけ `ckheal = 'g80'` として引き継ぐ。
- 記録は今の条件で計算し直すので、形式は変えない。記録の並べ替えは、ほかのタイプと同じく順位の基準（無補正比）で行う。
