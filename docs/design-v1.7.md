# ver1.7 設計書

レベルを Lv.50 / 60 / 70 / 80 から選べるようにし、サブスキルは常に5枠入力する。Lv.50 の期待値と確率を新しく出す。Lv.60・70・80 の値と分布は ver1.6 と同じ。作業の基準は `fa1daf1`。

## 1. 画面

画面イメージ: https://claude.ai/artifact/ACHuDEgA1hAuySFQYJcVhc

- **サブスキル**: 対象レベルの切り替え（Lv.50まで / 70まで / 80まで）をなくし、常に5枠（Lv.10 / 25 / 50 / 70 / 80）を出す。見出しの横に入力した枠の数（3/5枠）。
- **ダイアログ**: 5枠すべてが埋まると自動で閉じる。途中でも「閉じる」で閉じられる（これまでも同じ）。注記に、確率が出る枠の数を足す。
- **レベル**: 性能の欄の一番上に、数字だけの丸ボタン（50 / 60 / 70 / 80、直径42px）。入力の数に関係なく、いつでも押せる。
- **期待値**: 選んだレベルで、そのレベルで開いている枠に入っているサブスキルで計算する。未入力の枠は「なし」、未選択の性格は無補正（これまでと同じ扱いで、にとよんツールとも同じ）。
- **確率**: 開いている枠のサブスキル・性格（食材タイプは開いている枠の食材配列）がすべてそろうと出す。そろうまでは帯の値が「—」で、記録ボタンは押せない（これまでの未入力のときと同じ）。
- **帯の上の1行**: 「Lv.80・サブスキル5枠での確率」。足りないときは「Lv.80の確率は、サブスキル5枠・性格がそろうと出ます」のように足りない入力を出す。
- **食材配列**: Lv.50 では Lv.60 の枠を「未解放」と薄く出す。入れておくことはでき、Lv.60 以上で使う。

| レベル | サブスキルの枠 | 食材の枠 |
|---|---|---|
| 50 | 3（Lv.10・25・50） | 2（Lv.1・30） |
| 60 | 3 | 3 |
| 70 | 4 | 3 |
| 80 | 5 | 3 |

## 2. 計算

- 条件 `env` にレベル `lv` を足す。サブスキルの枠の数 `N` は `SLOTS_AT[lv]` で、分布の数え上げ（`buildDist`）はこれまでどおり `N` を使う。
- 計算に使うレベルは `levelOf(env)`（`lv`、なければ `LEVEL[N]`）。`lv` のない条件（テスト・比較スクリプト）は ver1.6 と同じ結果になる。
- 開いている食材の枠の数 `ingOpen(LV)` を `basics` で求める（`ingSlots`）。
  - きのみ・スキルタイプ: `amountPatterns(mon, k)` で開いている k 枠の個数の並びと出現率を使う。
  - 食材タイプ: `slotsOf(mon, arr, k)`・`allArrs(mon, k)` で開いている枠だけを数える。比較の基準（無補正で狙い食材が最も多い配列）も k 枠の配列（Lv.50 なら AA）。
- 食材おてつだいは、開いている枠から均等に1つ選ぶ（にとよんツールと同じ）。
- `envKey`・分布の保存のキーに `lv` が入るので、保存済みの分布は一度計算し直す。`MODEL_VERSION` は上げない。

## 3. 状態と記録

- レベルは `cklv` に保存する。まだなければ以前の対象レベル（`ckmode`: 3→60、4→70、5→80）から引き継ぐ。
- 記録には、低い枠から続けて入っているサブスキルをすべて保存する（Lv.60 で5枠入れて記録すれば5枠）。
- 一覧は、今のレベルで開いている枠がそろっている記録を出し、その枠だけで評価する。5枠の記録は Lv.50〜80 のどれでも、3枠の記録（以前の「Lv.50まで」を含む）は Lv.50・60 で出る。食材タイプは、開いている枠の食材配列が入っている記録だけを出す。
- 「表示中」の判定と入力への戻しも、開いている枠で比べる。戻すときは記録のサブスキルをすべて入れる。

## 4. 確かめたこと

- `tests/check-segs.mjs`: 221ケース OK。
- `tests/check-dist.mjs`: 9ケース OK（Lv.50 の3タイプを足した）。
- `tests/compare-values.mjs`（変更前 `fa1daf1` と比較）: 8,000件、最大絶対差0。`lv` を渡した条件（60・70・80）でも最大絶対差0。
- 分布: 3タイプ（3枠・4枠）で、`lv` を渡した新しいエンジンと変更前の分布が完全一致。
- にとよんツール（`nitoyon/pokesleep-tool` の `1571741`）: `tests/compare-nitoyon.mjs` を Lv.50 / 60 / 80 で比べるようにした。
  - きのみ 19,530件・食材 299,250件は、Lv.50 を含めて相対差が最大 2.0e-15（浮動小数の誤差のみ）。
  - スキルは相対差の中央値 2.2%で、Lv.50 も Lv.60・80 と同じ程度。満タン後のキュー4回の違いによるもので、ver1.5 からの既知の差（[設計書 ver1.5](design-v1.5.md) の6章）。
- ブラウザ（Chromium）: スキルタイプで、未入力 → 3枠入力して途中で閉じる → 性格 → Lv.80（確率は「—」・案内）→ Lv.60・50（確率が出る）→ 記録 → Lv.80 の一覧に3枠の記録が出ない → 5枠目まで入れるとダイアログが閉じて Lv.80 の確率が出る、を確かめた。食材タイプの Lv.50 で Lv.60 の枠が「未解放」になり、Lv.1・30 の枠が入れば確率を出すことも確かめた。
