# ver1.4 要件定義：スキルタイプの分布計算の高速化

ver1.3（`03d095d6`、PR #43）を土台に、スキルタイプの上位%の計算時間を短くする。作業ブランチは `codex/checker-v1.4-improvements`。今回は高速化だけを対象とする。

## 1. 現状

| 項目 | main の確認結果 |
|---|---|
| 計算 | `js/calc.js` の `runSegs` が日をまたいで天井カウンタの分布を追う |
| 重い部分 | 抽選が止まる各時点で、天井カウンタ全体を足し合わせる `collect` |
| 使い回し | `skill/calc.js` には抽選回数の分布・`runSegs` の結果のキャッシュが既にある |
| 実行 | Web Worker 1個。計算済みの分布は IndexedDB に保存 |
| 確認 | `check-dist.mjs` は3タイプ各2条件。変更前後の比較は未整備 |

## 2. 方針

- 先に、同じ条件で変更前後の値と計算時間を比べる手順を用意する。
- `runSegs` の状態の更新・足し合わせを優先して最適化する。
- 計算の順番や、前に計算した個体に結果を依存させない。
- 天井・ストック2回・満タン後のキュー4回・小数回数の混合・収束条件は変えない。
- Worker の複数化は、単体の計算を改善した結果を見て判断する。

## 3. 完了条件

| 確認 | 条件 |
|---|---|
| 整合性 | `node tests/check-dist.mjs` が通る |
| 個体の値 | 全125匹 × 条件4 × サブスキル4 × 性格4を変更前後で比較する。きのみ・食材は完全一致。スキルは絶対・相対誤差1e-12以内 |
| 分布 | スキル5枠の常にタップ・3時間ごと、それぞれヒーラー整数・小数の4条件で、行数・無補正比・確率・同等以上の確率を比較する |
| 境目 | 天井前後・ストック上限・キュー・小数回数を小さな独立モデルで確認する |
| 時間 | 同一環境・同一条件・新しいプロセスで複数回計測し、中央値を記録する。保存済みの分布は使わない |
| 保存 | `MODEL_VERSION` を7から8に上げる |

## 4. 今回は扱わないもの

進化データの照合、所持数の表示、受け取り規則の出典調査、にとよんツールとの比較、認証の変更、評価モデルの追加、データ更新、3タイプ全体の共通化。引き継ぎの残件として別に扱う。

実装後に `design-v1.4.md` と README に作り・検証結果を記す。
